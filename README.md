# CFF Trainer: feedback

Bug reports and doctrinal feedback for **[CFF Trainer](https://benstrube.github.io/cff-trainer/)**, an unofficial
call-for-fire practice tool for forward observers. This repository holds **issues only**; the trainer's source is not here.

## Report a bug
- **Easiest:** in the trainer, open **Help → Report a bug**. It fills in the version, settings and exercise seed (so the problem can be replayed) and opens a pre-filled issue here.
- **Or:** [open a new report](https://github.com/benStrube/cff-trainer-feedback/issues/new/choose).

No GitHub account? In the trainer, use **Copy report** or **Save report file** and share it however suits you.

Nothing is sent automatically. You see the full report before you submit it. Please don't include personal or sensitive information.
